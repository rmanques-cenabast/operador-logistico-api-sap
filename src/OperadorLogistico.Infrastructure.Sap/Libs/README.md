# Carpetas para DLLs de SAP
Este directorio está destinado a almacenar las DLLs oficiales de SAP Connector para .NET (`sapnco.dll` y `sapnco_utils.dll`).

## Instrucciones para agregar las DLLs:
1. Copia `sapnco.dll` y `sapnco_utils.dll` (versión 64-bit / .NET 8+) en esta carpeta.
2. Agrega las referencias en `OperadorLogistico.Infrastructure.Sap.csproj`.
